# AIML Learning Repo

Learning AI/ML step by step, starting with Python.

## Overview

- Python fundamentals
- Data handling and visualization
- Machine learning
- Deep learning
- GenAI and AI engineering tools
- Supporting tools and workflows

## Roadmap

### 1. Programming Foundation
- **Python from Scratch:** Core syntax, logic building, data structures, and algorithmic fundamentals.

### 2. Data Handling & Manipulation
- **Data Collection & Pre-processing:** Cleaning noisy data, handling missing values, and normalization.
- **Exploratory Data Analysis (EDA):** Data visualization tools and analytical libraries.

### 3. Essential Mathematics for AI
- **Core Math:** Foundational concepts in Statistics and Probability required to understand how learning models optimize and predict.

### 4. Machine Learning (ML)
- **Supervised Learning:** Classification and regression models.
- **Unsupervised Learning:** Clustering and association algorithms.
- **Reinforcement Learning:** Core concepts and feedback loops.
- **Core Algorithms:** SVM (Support Vector Machines), Decision Trees, KNN, and Logistic Regression.
- **Evaluation Metrics:** Bias-Variance tradeoff, Precision, Recall, and F1-Score.
- **API Integration:** Hands-on integration with OpenAI APIs.

### 5. Deep Learning (DL)
- **Foundations:** Perceptrons and neural network fundamentals.
- **Architectures:** Feedforward Neural Networks (FNN), Recurrent Neural Networks (RNN), and Convolutional Neural Networks (CNN).
- **Transformers:** Transformer architectures and attention mechanisms powering modern LLMs.
- **Frameworks:** Implementation using TensorFlow and PyTorch.

### 6. Generative AI & Advanced Domains
- **LLMs & GenAI:** Large Language Models, prompt engineering, and fine-tuning.
- **RAG & GANs:** Retrieval-Augmented Generation (RAG) pipelines and Generative Adversarial Networks.
- **Specializations:** Natural Language Processing (NLP) and Computer Vision (CV).

### 7. Software Engineering & Deployment Tools
- **Backend & Web:** Building web endpoints for models using Flask alongside foundational HTML/CSS/JS.
- **Data Queries:** SQL for database management and querying.
- **DevOps & Versioning:** Git & GitHub for collaboration, and Docker & Kubernetes for containerization and deployment.

### 8. Projects & Career Readiness
- **Domain-Specific Projects:** Building minor and major capstones across Finance, Healthcare, E-commerce, and Entertainment.
- **Career Preparation:** Technical resume structuring, LinkedIn optimization, and off-campus interview preparation.
