# Python Learning Folder

This folder contains beginner-friendly Python practice files organized by day and topic.

## Structure

- Day 2: Basics, operators, typecasting, arithmetic
- Day 3: Conditionals, loops, functions, recursion, strings, practice questions
- Day 4: Lists, tuples, sets, dictionaries, formatting, strings, practice questions

Each day also includes a NOTES.MD file with supporting theory or reminders.

## How to Run

Most files are standalone scripts. Run from a terminal:

```bash
python "Python/Day 3/Loops/01_for_loop.py"
```

Some scripts prompt for input, so run them in an interactive terminal.

## Conventions

- Files are numbered to indicate suggested study order.
- Comments are written for learning and revision.
- `match-case` examples require Python 3.10 or newer.
